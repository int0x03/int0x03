## 核心能力

- **故障诊断：** 分析应用指标与运行数据，梳理系统故障的症状、影响与因果关系，
  在高并发、高流量的生产环境中快速定位并解决问题
- **可靠性管理：** 设置基于SLA（Service Level Agreement）、SLI
  （Service Level Indicator）、SLO（Service Level Objective）、
  的容量规划及服务可用性、延迟和性能目标的持续监控与评估
- **事件管理：** 事件响应与复盘、根因分析（Root Cause Analysis，RCA）、设置检测时间
  （Time to Detect，TTD）、恢复时间（Time to Restore，TTR）和平均恢复时间
  （Mean Time to Restore，MTTR）等指标
- **Java 性能调优：** 垃圾回收（Garbage Collection，GC）调优、线程分析、堆栈
  分析及内存泄漏分析
- **可观测性：** 指标采集、日志聚合、分布式追踪分析，以及 Prometheus、Grafana、
  Loki 和 OpenTelemetry
- **智能诊断：** 基于机器学习与大语言模型开展告警、日志和指标分析，以及智能体
  （Agent）与技能（Skill）的迭代开发
- **云平台与容器：** Linux、OpenStack、Kubernetes、容器化的版本化配置与自动化管理
- **分布式系统：** 高可用、高并发、高流量系统的建设与运营，以及微服务、云原生和
  开发运维（Development and Operations，DevOps）实践
- **开发与交付：** 熟练使用 Python 开发生产级软件和运维自动化工具，并具备 Java、
  Shell、持续集成与持续交付（Continuous Integration and Continuous Delivery，
  CI/CD）经验
- **全球流量：** 熟悉内容分发网络（Content Delivery Network，CDN）、多层负载均衡及
  跨地域流量管理

## 代表项目

### Sherlock.ai

- 构建结合人工智能（Artificial Intelligence）与大语言模型的自动化问题诊断
  框架，采用 Agent、Skill 与检索增强生成（Retrieval-Augmented Generation，RAG）
  相结合的方式，将人工诊断流程转化为 Agent 自动分析流程，并持续迭代诊断能力。
- 基于公司内部的 Agent 运行框架组织问题上下文，调用 Skill 和 RAG 获取内部静态与
  动态知识，并通过API（Application Programming Interface）和
  模型上下文协议（Model Context Protocol，MCP）获取指标、日志、链路、拓扑及配置
  等信息，最终生成根因判断与修复建议。
- 记录完整的分析与诊断过程，并在后续分析中复用，以验证 Skill 的有效性并支持持续
  优化。
- 对 Skill 和 RAG 文档进行分层、分类、整理与迭代更新。
- 定期回放典型事件并进行评分，评估诊断效果，推动 Skill 和 RAG 文档的持续改进。

### Lepenseur

- 在 Agent 运行框架尚未成熟的阶段，构建基于大语言模型的自动问答系统，响应用户在
  监控、告警、日志、追踪和拓扑等方面的问题。
- 收集过去一年的真实问答数据，经过清洗、筛选和分类后构建 RAG 知识库；选取典型
  问题，由相关值班工程师评分，以评估系统能力。
- 根据 RAG 内容梳理 Agent 所需的工具，对工具进行分类整合，形成 Agent 技能库。
- 在用户提问后由 Agent 自动介入，并发探索可能的问题方向，汇总结论并回复用户；
  同时保存完整的分析轨迹，用于后续复盘和能力优化。

### SLO 自动优化系统
- 根据系统已有的 latency, traffic 等指标估算当前特定 URL 的 SLO 合理区间值, 并推荐用户修改设置
- 对于一定时间窗口内不能满足 SLO 的 URL, 通过分析 tracing 数据和日志数据, 找出潜在的问题, 并给出优化建议
- 对于关键重要的 URL, 结合日志和代码, 静态分析代码, 找出潜在的性能问题, 并给出优化建议

### Groot

- 面向各业务线的告警，自动分析其关联的应用程序及基础设施的指标曲线，推断潜在
  各种原因，并通过机器学习模型对原因的可能性进行排序, 最后作出推荐。
- 从历史线上故障中提取经验，包括告警信息、相关应用、核心指标、关键日志、业务域
  与应用之间的拓扑关系，以及历史配置变更等，做为原始数据使用机器学习产生模型。
- 使用基于统计的异常检测算法和相似性算法, 对比告警信号和应用/基础设施指标, 过滤并排序.
