# LeetCode

Notes on algorithmic patterns and lessons learned from practice problems.

## Topics to explore

- Arrays, hash maps, and two pointers.
- Sliding windows and binary search.
- Trees, graphs, and traversal.
- Dynamic programming and greedy strategies.

## Suggested problem-note structure

1. Summarize the problem in your own words.
2. Record constraints and edge cases.
3. Explain a straightforward approach and its limitations.
4. Describe the improved approach and why it works.
5. Include your solution, time complexity, and space complexity.

Link to the original problem rather than copying its full statement.
