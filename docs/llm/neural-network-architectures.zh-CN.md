# 神经网络架构：从感知机到 Transformer

[English]({{ '/llm/neural-network-architectures/' | relative_url }})

为什么会有这么多种神经网络架构？每一种重要设计的出现，都是因为此前的设计难以处理某种特定结构：像素之间存在邻域关系，句子具有顺序，图由连接关系构成，而生成任务所需要的能力不只是分类。

本文按照大致的时间顺序介绍主要架构家族。文中的日期代表有影响力的里程碑，而不是某个想法诞生的唯一时刻。研究思想通常会经历多年的发展，而且往往要过很久才能真正投入实践。本文根据每个家族最早的思想源头排序；后来的衍生模型仍归在所属家族中，因此部分时间范围会相互重叠。

![神经网络主要架构里程碑时间线]({{ '/assets/llm/neural-network-timeline.zh-CN.svg' | relative_url }})

## 先看懂地图，再走进时间线

人工神经网络（Artificial Neural Network，ANN）是一组由可学习权重连接起来的简单计算单元。**架构**规定这些单元如何连接，以及信息如何在它们之间流动。

本文介绍的大多数架构都着重于以下四种连接模式之一：

![四种反复出现的神经网络连接模式]({{ '/assets/llm/architecture-patterns.zh-CN.svg' | relative_url }})

| 模式 | 它所做的假设 | 代表性家族 |
| --- | --- | --- |
| 稠密连接 | 每个输入都可能与每个输出发生交互。 | 前馈网络 |
| 局部连接 | 相邻的数值能够构成有意义的模式。 | 卷积网络 |
| 循环连接 | 较早的状态会影响后续状态。 | 循环网络 |
| 选择性连接 | 模型应当选择哪些词元、节点或专家最重要。 | Transformer、图网络、混合专家模型 |

这些家族并非彼此互斥。例如，自编码器描述的是一种训练结构，而其中的编码器本身可以采用卷积、循环或 Transformer 架构。

## 1957—1986 年：感知机与前馈网络

### 它们要解决的问题

早期研究者希望机器能够根据样本学会决策规则，而不是完全依赖人工编写的程序。弗兰克·罗森布拉特（Frank Rosenblatt）在 1957 年提出、并于 1958 年发表的感知机，可以学习两个类别之间的线性边界。

单个感知机无法解决需要多阶段推理的问题。把多个单元堆叠成前馈神经网络（Feedforward Neural Network，FNN），就能够表示更复杂的函数。1986 年，反向传播算法得到推广，为调整多层网络中的权重提供了有效方法。

```text
输入特征              隐藏表示                     预测结果
[x1, x2, x3]  ───→  [第 1 层] ───→ [第 2 层] ───→ 类别或数值
```

### 主要特点

- 信息沿单一方向从输入流向输出。
- 多层感知机（Multilayer Perceptron，MLP）通常把一层中的每个单元与下一层中的每个单元相连。
- 隐藏层和非线性激活函数使网络能够表示弯曲或不连续的决策边界。
- 这种架构几乎不对输入的组织方式作出假设。

### 适用范围

MLP 适用于表格数据分类、回归、紧凑特征学习，也常用作大型模型末端的预测头。它简单而通用，因此至今仍是重要的基线模型。

### 主要局限

全连接层会忽略已知的数据结构。把图像展平会破坏相邻像素之间的关系，而独立处理每个时间步则会丢失序列顺序。

## 1980—1998 年：卷积网络学习局部模式

### 它们要解决的问题

图像的数据量很大，而且同一种视觉特征可能出现在任意位置。让每个像素与每个隐藏单元相连，不仅会浪费参数，也无法自然地复用边缘或角点检测器。

1980 年出现的神经认知机引入了一种具有重要影响的分层、位置偏移容忍视觉设计。随后，包括 20 世纪 80 年代末和 90 年代 LeNet 在内的可训练卷积神经网络（Convolutional Neural Network，CNN），把这一原理发展成了实用的识别系统。

```text
图像 → 边缘图 → 形状与部件 → 物体表示 → 预测
       小型局部滤波器会在整幅图像上重复使用
```

### 主要特点

- 小型滤波器在输入上滑动，并在所有位置共享同一组权重。
- 浅层检测局部模式，深层把它们组合成更大的结构。
- 池化或步幅操作可以在保留重要特征的同时降低分辨率。
- 局部连接为 CNN 提供了适合空间数据的强归纳偏置。

### 适用范围

CNN 适用于图像分类、目标检测、图像分割、医学影像、音频频谱图和一维传感器序列。重要的衍生架构包括 AlexNet、视觉几何组网络（Visual Geometry Group network，VGG）、残差网络（Residual Network，ResNet）、DenseNet、EfficientNet 和 U-Net。

### 主要局限

CNN 天生关注局部区域。要连接距离很远的区域，可能需要非常深的网络、更大的卷积核或其他机制。它内置的“平移友好的局部模式”假设并不适合所有数据集。

## 20 世纪 80 年代—1997 年：循环网络赋予序列记忆

### 它们要解决的问题

前馈模型接收固定输入并产生固定输出，但语言、语音和时间序列会逐步展开。当前数值的含义往往取决于此前发生过什么。

循环神经网络（Recurrent Neural Network，RNN）在每个时间步复用同一个状态转移函数，并把隐藏状态向后传递。循环系统研究在 20 世纪 80 年代持续发展。1997 年提出的长短期记忆网络（Long Short-Term Memory，LSTM）着重解决跨越多个时间步学习依赖关系的困难。

```text
                      ┌──────── 隐藏状态 ────────┐
                      │                           ▼
时间步 1：x1 → [RNN 单元] → h1   时间步 2：x2 → [同一单元] → h2 → ...
```

### 主要特点

- 隐藏状态是对较早输入的压缩总结。
- 参数在时间维度上共享，因此可以处理不同长度的序列。
- LSTM 使用门控结构决定哪些内容需要写入、保留和输出。
- 2014 年提出的门控循环单元（Gated Recurrent Unit，GRU）是一种更简单的门控替代方案。

### 适用范围

RNN 适用于预测、序列标注、语音、手写识别和规模较小的语言系统。当数据以流式方式到达、延迟必须很低，或者模型需要维护紧凑状态时，它仍然很有价值。

### 主要局限

基本 RNN 容易出现梯度消失或梯度爆炸。门控变体改善了记忆能力，但循环处理必须按顺序执行，因此难以在长序列上充分并行。

## 20 世纪 80 年代—2013 年：自编码器学习有用的瓶颈表示

### 它们要解决的问题

标注数据成本高昂，而原始样本通常很丰富。研究者需要一种能够直接从输入中学习有用表示，并且无需人工定义所有特征的数据压缩方法。

自编码器会学习让输入通过受限的中间表示后再复制自身。20 世纪 80 年代的研究已经使用反向传播来学习这种内部编码。后来的变体进一步让瓶颈表示具备稀疏性、抗噪能力或概率性质。

```text
输入 ──→ 编码器 ──→ 紧凑编码 ──→ 解码器 ──→ 重建结果
 │                                              │
 └────────────── 比较输入与输出 ────────────────┘
```

### 主要特点

- 编码器压缩输入，解码器负责重建。
- 瓶颈、噪声或其他约束可以防止模型只做简单复制。
- 学到的编码可以捕捉能够解释数据常见模式的因素。
- 2013 年提出的变分自编码器（Variational Autoencoder，VAE）学习一个平滑的概率潜在空间，并可从中采样生成新样本。

### 适用范围

自编码器适用于降维、去噪、表示学习、压缩、异常检测和生成任务。卷积自编码器常用于图像，而序列自编码器则用于文本或时间序列。

### 主要局限

较低的重建误差并不能保证表示有用或容易解释。能力过强的解码器甚至可能很好地重建异常输入，从而削弱异常检测效果。

## 1991 年：混合专家模型进行任务分工

### 它们要解决的问题

即使数据中包含差异很大的子问题，普通模型也必须对每个样本使用相同的计算过程。例如，手写识别模型可能会受益于分别处理不同书写风格的专家。

1991 年提出的自适应混合专家模型（Mixture of Experts，MoE）训练一个门控网络，把样本分配给不同的专家网络。

```text
                 ┌→ 专家 A ─┐
输入 → 路由器 ───┼→ 专家 B ─┼→ 加权或选定的输出
                 └→ 专家 C ─┘
```

### 主要特点

- 多个专家子网络分别学习不同的数据区域或输入类型。
- 路由器为专家分配权重，或者只选择其中一小部分。
- 现代稀疏 MoE 层只会为每个词元激活少数专家。
- 模型容量的增长速度可以超过处理单个样本所需计算量的增长速度。

### 适用范围

MoE 适用于大型多样化数据集、多任务系统，以及超大规模语言或视觉模型。现代实现通常把稀疏专家层放入 Transformer 中。

### 主要局限

路由负载很难保持均衡。一些专家可能收到过多任务，而另一些专家几乎学不到内容；分布式系统还必须高效地在设备之间传输激活值。

## 1993 年：孪生网络学习“相似”的含义

### 它们要解决的问题

普通分类器只能从训练阶段见过的类别中做出选择，而验证任务问的是另一个问题：两个样本是否来自同一个人或同一类别，即使模型以前没有见过这个类别？

1993 年为签名验证提出的孪生网络，会让两个输入通过参数完全共享的相同子网络，再比较它们的嵌入表示。

```text
输入 A → 共享编码器 → 嵌入 A ─┐
                               ├→ 距离 → 相同或不同
输入 B → 共享编码器 → 嵌入 B ─┘
```

### 主要特点

- 两个或更多分支使用完全相同的参数。
- 训练过程会拉近匹配样本，并推远不匹配样本。
- 输出是相似度或距离，而不是固定的类别身份。

### 适用范围

孪生网络适用于人脸与签名验证、图像匹配、语义搜索、重复内容检测和少样本学习。如今，这一更广泛的思想通常被称为度量学习或对比学习。

### 主要局限

性能高度依赖正负样本对的选择方式。如果训练样本对不能代表真实部署环境，嵌入表示可能会学到投机取巧的捷径。

## 2005—2016 年：图网络沿关系传播信息

### 它们要解决的问题

像素位于规则网格上，词语构成序列；但分子、道路、社交网络和知识库拥有不规则的连接关系。把图展平会丢失定义其结构的边。

早期图神经网络（Graph Neural Network，GNN）形式在 2005 年出现，并在 2009 年得到进一步发展。后来的消息传递方法和图卷积网络（Graph Convolutional Network，GCN）在 2010 年代中期推动了实用图学习的普及。

```text
A ─── B        每个节点接收来自邻居的消息
│   ╱ │        B 汇总来自 A、C 和 D 的信息
C ─── D        重复多层后，信息可以传播到更远处
```

### 主要特点

- 节点通过聚合邻居发送的消息来更新自身表示。
- 共享更新规则可以处理大小和形状不同的图。
- 节点、边和整张图的特征都可以参与预测。
- 图注意力网络（Graph Attention Network，GAT）会学习哪些邻居应该获得更高权重。

### 适用范围

GNN 适用于分子性质预测、推荐、欺诈检测、交通预测、知识图谱、物理系统和社交网络分析。

### 主要局限

深层消息传递可能让不同节点的表示变得过于相似，这一问题称为过度平滑。大规模图还会带来采样、内存和分布式训练方面的挑战。

## 2014 年：对抗网络把生成变成一场博弈

### 它们要解决的问题

有用的生成模型必须产生逼真的样本，但直接定义一个“看起来像真实图像”的评分标准并不容易。2014 年提出的生成对抗网络（Generative Adversarial Network，GAN）通过竞争过程来学习这个评分标准。

![自编码器、生成对抗网络与扩散模型工作流程对比]({{ '/assets/llm/generative-models.zh-CN.svg' | relative_url }})

### 主要特点

- 生成器把随机输入转换成合成样本。
- 判别器学习区分真实样本与生成样本。
- 生成器通过学习欺骗判别器来不断改进。
- 训练不需要显式的逐像素重建目标。

### 适用范围

GAN 在逼真图像合成、图像到图像转换、超分辨率、风格迁移和合成训练数据等领域具有重要影响。著名的衍生架构包括深度卷积生成对抗网络（Deep Convolutional Generative Adversarial Network，DCGAN）、CycleGAN 和 StyleGAN。

### 主要局限

两个相互竞争的网络可能很难稳定训练。即使单个样本看起来很逼真，生成器也可能只产生范围狭窄的输出，这种现象称为模式崩溃。

## 2015—2020 年：扩散模型学习逆转噪声

### 它们要解决的问题

GAN 可以生成清晰的样本，但对抗训练不够稳定，而且可能遗漏数据分布中的某些部分。扩散模型采用了更稳定的学习任务：从逐渐变得嘈杂的数据中恢复干净样本。

现代扩散模型形式于 2015 年出现。去噪扩散概率模型（Denoising Diffusion Probabilistic Model，DDPM）在 2020 年展示了高质量图像生成能力，后来的潜在空间方法进一步提高了效率。

```text
训练：干净样本 → 分多步加入噪声 → 接近纯噪声
采样：随机噪声 → 反复移除预测噪声 → 新样本
```

### 主要特点

- 固定的前向过程使用噪声逐步破坏数据结构。
- 神经网络学习反向去噪步骤。
- 与平衡一对对抗网络相比，其训练过程更加稳定。
- 引导机制可以使用文本、标签或其他条件来控制采样。

### 适用范围

扩散模型适用于图像、音频、视频、三维内容、分子和时间序列生成，也可用于图像修复与可控编辑。

### 主要局限

传统生成过程需要多次运行神经网络。更快的采样器和潜在扩散技术降低了成本，但推理速度仍可能慢于单次前向传播的生成器。

## 2017 年至今：Transformer 直接连接远距离信息

### 它们要解决的问题

RNN 必须让信息经过每个中间时间步，并按顺序处理词元。因此，远距离关系难以保留，训练过程也无法充分利用并行硬件。

2017 年提出的 Transformer 使用自注意力取代循环结构。每个词元都可以直接从同一序列中的其他相关词元获取信息。

![自注意力在相关词元之间传递信息]({{ '/assets/llm/transformer-attention.zh-CN.svg' | relative_url }})

### 主要特点

- 自注意力会根据上下文，对其他词元的表示进行加权组合。
- 注意力本身不区分排列顺序，因此需要位置信息告诉模型词元的先后关系。
- 训练时可以并行处理许多词元。
- 仅编码器模型擅长理解任务，仅解码器模型擅长生成任务，而编码器—解码器模型擅长序列转换。

### 适用范围

Transformer 被广泛用于翻译、摘要、搜索、代码生成、语音和多模态系统，也是大多数现代大型语言模型（Large Language Model，LLM）的基础。视觉 Transformer（Vision Transformer，ViT）在 2020 年把这一设计应用到图像块。Transformer 还服务于时间序列、生物学、机器人和推荐任务。

### 主要局限

完整注意力会比较每个词元与其他所有词元，因此内存和计算量会随序列长度快速增长。大型模型还需要大量数据与硬件，并要求严格的评估和部署保障措施。

## 这些架构家族如何相互配合

现代系统很少只使用一个架构家族：

- CNN 或 ViT 可以先编码图像，再由 Transformer 生成图像描述。
- GNN 可以先编码分子，再由扩散模型提出新的分子结构。
- 自编码器可以压缩图像，使扩散过程在更小的潜在空间中运行。
- Transformer 可以用稀疏 MoE 层替换部分 MLP 模块。
- 孪生网络的训练目标可以教会 CNN 或 Transformer 编码器学习有用的嵌入表示。

架构名称回答的是**信息如何流动**，训练目标回答的是**模型要学会做什么**。两者不能混为一谈：Transformer 可以通过训练完成分类、重建、预测、比较或生成任务。

## 快速选择指南

| 你的数据或目标 | 合理的起点 | 原因 |
| --- | --- | --- |
| 表格数据分类或回归 | MLP | 结构假设少，是简单可靠的基线 |
| 具有局部模式的图像 | CNN | 高效的局部滤波器与权重共享 |
| 流式或中等长度序列 | LSTM 或 GRU | 状态紧凑，支持增量处理 |
| 长序列或多模态上下文 | Transformer | 直接建立长距离交互，并支持并行训练 |
| 压缩、去噪或异常评分 | 自编码器 | 学习受约束的重建过程 |
| 样本配对或少样本识别 | 孪生网络 | 学习可复用的相似度空间 |
| 分子、网络或相互连接的实体 | GNN | 保留不规则连接关系 |
| 快速的单次图像生成 | GAN | 训练完成后可直接采样 |
| 高质量可控生成 | 扩散模型 | 稳定的去噪目标与灵活的引导方式 |
| 超大规模的条件容量 | MoE | 无需使用所有参数即可激活专业模块 |

应当从能够表达数据结构的最简单架构开始。更流行的模型不一定更好；请针对真实部署任务比较准确率、数据需求、延迟、内存、可解释性和维护成本。
