# 第 5 课：把滑动窗口变成机器学习特征

[English]({{ '/time-series-anomaly-detection/lessons/05-classical-machine-learning/' | relative_url }})

## 每个点都正常，形状却可能异常

读数 `20, 24, 20, 16, 20` 全都处于有效范围，但反复快速振荡可能说明控制器不稳定。可以把几个相邻点表示为一个样本：

```text
序列：   20 21 22 21 20 19
窗口 1： [20 21 22]
窗口 2：    [21 22 21]
窗口 3：       [22 21 20]
```

当窗口长度为三、步长为一时，相邻样本会重叠。同一次事故产生的所有窗口必须处于时序划分的同一侧。

## 把每个窗口变成有意义的描述

有两种常见表示：

1. **原始窗口：**保留每个有序数值，例如 `[20, 21, 22]`。
2. **工程特征：**概括水平、离散程度和形状。

| 特征 | 它回答的问题 |
| --- | --- |
| 滞后值 | 前一步或前几步发生了什么？ |
| 均值、标准差、最小值、最大值 | 窗口的水平和离散程度如何？ |
| 差分或斜率 | 是否正在移动，速度多快？ |
| 最长重复段 | 传感器是否卡死？ |
| 季节残差统计量 | 去掉预期上下文后是否异常？ |
| 频域能量 | 是否存在异常振荡？ |

特征应该对应具体事故故事。数百个无法解释的特征只会增加调试和漂移监控难度。

## 让检测器匹配数据形状

| 方法 | 直观理解 | 重要提醒 |
| --- | --- | --- |
| Isolation Forest | 异常样本只需较少随机切分就会被孤立。 | 评分表示相对罕见程度，不代表业务危害。 |
| 局部离群因子（Local Outlier Factor，LOF） | 如果一个点的邻域比附近邻域稀疏，它就很可疑。 | 为未来样本评分时使用 novelty 模式。 |
| 单类支持向量机（One-Class Support Vector Machine，SVM） | 在大部分正常样本周围画出灵活边界。 | 缩放和超参数会显著影响边界。 |
| Elliptic Envelope | 拟合稳健的高斯形状数据云。 | 正常数据存在多种模式或不是椭圆形时不合适。 |
| 聚类/最近邻 | 计算样本到正常群体或邻居的距离。 | 维度很高且噪声很多时，距离会失去意义。 |
| 主成分分析（Principal Component Analysis，PCA） | 学习低维正常子空间，并使用重构误差评分。 | 线性重构无法表示非线性关系。 |

[scikit-learn 离群值检测指南](https://scikit-learn.org/stable/modules/outlier_detection.html)区分了两种设置：**离群值检测**允许训练数据包含异常；**新颖性检测**使用大体干净的正常历史学习，再为新观测评分。这个选择会改变方法假设和调用接口。

## 建立一条按时间运行的流水线

```text
过去原始数据 → 窗口 → 特征 → 插补器 → 缩放器 → 检测器 → 分数
                    所有组件只使用训练时段拟合
未来数据     → 相同的冻结变换 ------------------------→ 分数
```

基于距离和边界的模型尤其需要特征缩放。缩放器只能在训练特征上拟合。窗口也必须满足因果关系：在 10:00 评分的窗口不能结束于 10:05。

把窗口分数关联到一个有文档说明的时刻，通常是窗口最后一个时间戳。然后合并相邻的高分窗口，避免一次事故淹没运维人员。

## 何时不该使用机器学习

如果季节残差加稳健阈值已经满足告警预算和检测延迟要求，学习模型可能只增加维护成本而没有增加价值。只有为了解决明确缺失的能力，例如非线性特征交互或异常形状，才使用更复杂模型。

## 本课检查清单

- [ ] 根据预期事故持续时间设置窗口长度和步长。
- [ ] 解释每个特征捕获的现象。
- [ ] 有意识地选择离群值检测或新颖性检测。
- [ ] 只在过去训练数据上拟合窗口、插补器、缩放器和模型。
- [ ] 将事件级结果与统计基线比较。
