# 第 6 课：理解深度时序模型

[English]({{ '/time-series-anomaly-detection/lessons/06-deep-time-series-models/' | relative_url }})

## 从需要学习的关系开始

假设服务有三个信号：流量、处理器使用率和延迟。在大流量下，200 毫秒延迟可能很正常；在几乎没有流量时，同样的延迟却很可疑。每个值单独看都合理，但它们之间的关系错了。

```text
时间 ───────────────→
流量：      低  低  低
处理器：    低  低  低       数值：合理
延迟：      低  低  高       关系：可疑
```

当长期时间依赖、非线性传感器关系、大规模数据或缺失观测让简单特征失效时，深度模型才更有价值。“深度”本身并不是一种异常评分机制。

## 产生分数的四种方式

| 机制 | 训练任务 | 异常分数 | 代表性模型 |
| --- | --- | --- | --- |
| 基于预测 | 预测下一个点或窗口。 | 预测误差或低预测似然。 | 循环神经网络（Recurrent Neural Network，RNN）、长短期记忆网络（Long Short-Term Memory，LSTM）、时序卷积网络（Temporal Convolutional Network，TCN）、Transformer |
| 基于重构 | 压缩并重建正常窗口。 | 输入与重构结果之间的差异。 | 自编码器、变分自编码器、序列自编码器 |
| 概率方法 | 学习正常序列或状态的分布。 | 低似然或异常状态转移。 | 状态空间模型、隐马尔可夫模型、归一化流 |
| 表示学习/图方法 | 学习嵌入和变量关系。 | 到正常表示的距离或被破坏的图关系。 | 对比学习模型、时序 Transformer、图神经网络 |

```text
预测：   过去窗口 → 模型 → 下一个预期值 → 误差
重构：   窗口 → 编码器 → 紧凑编码 → 解码器 → 重建 → 误差
图模型： 传感器节点 + 关系 → 预期联合状态 → 关系误差
```

学习方式是另一个独立维度。预测隐藏片段或未来片段可以是**自监督**任务，因为序列本身提供了目标。模型也可以只用已知正常历史做半监督新颖性检测，或使用事故标签做监督分类。

## 多变量数据：关系失效同样重要

选择图模型或注意力模型前，先确认变量是否真的相互影响，以及关系是否稳定。传感器名称、单位和拓扑可能与数值同样重要，否则模型可能只学到一次部署后就会消失的偶然相关性。

保留特征身份和可用性掩码。如果运维人员需要根因线索，既要评估完整事件的检测效果，也要评估模型能否指出受影响变量。

## 缺失值本身描述了数据可用性

```text
数值： [12, 13,  ?,  ?, 15]
掩码： [ 1,  1,  0,  0,  1]
```

不要悄悄把缺失值变成零。有些模型会同时接收数值、掩码和时间间隔。[PyPOTS](https://github.com/WenjieDu/PyPOTS) 的全称是面向部分观测时序数据挖掘的 Python 工具箱（Python Toolbox for Data Mining on Partially-Observed Time Series）。它为多个神经模型和任务提供接口，是**工具箱**，不是某一种异常检测算法；使用时仍要说明具体模型和评分机制。

## 更大模型容量也有代价

深度模型需要更多数据、调参、算力、阈值校准和漂移监控。不同重训运行的分数可能不一致，也可能难以解释。比较时必须使用与简单基线相同的时序划分、事件定义和告警预算。

只有当它改善了实际结果——更早发现、发现更多真实事件、减少误报，或提供有用的多变量定位——才值得使用。
