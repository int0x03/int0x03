# 时序数据异常检测

关于识别时序数据中异常观测值和异常模式的笔记。

[English]({{ '/time-series-anomaly-detection/' | relative_url }})

时序异常检测并不存在一种唯一且互斥的分类方式。同一种方法可以同时属于统计方法、无监督方法和基于预测的方法。通常可以从多个维度对问题进行分类：什么情况构成异常、检测器如何学习，以及检测器如何产生异常分数。

## 什么是异常？

| 类型 | 描述 | 示例 |
| --- | --- | --- |
| 点异常（Point anomaly） | 单个观测值本身就很异常。 | 温度读数为 200°C。 |
| 上下文异常（Contextual anomaly） | 某个值只在特定的时间上下文中异常。 | 凌晨 03:00 出现通常只会在中午 12:00 出现的高流量。 |
| 集合异常（Collective anomaly） | 即使每个点单独看来都合理，整个序列仍然异常。 | 长时间保持不变的平线或异常振荡。 |
| 变点（Change point） | 数据生成过程发生变化。 | 均值、方差或趋势发生持续性改变。 |

区分这些类型非常重要：全局阈值也许能检测点异常，却可能漏掉异常形状、季节性偏差或持续性的状态转变。

## 主要方法类别

### 1. 统计与规则方法

这类方法估计数据的预期范围或分布，并标记偏差足够大的观测。它们速度快、可解释性强，也是很好的基线方法。

| 方法 | 基本思路 | 说明 |
| --- | --- | --- |
| Z-score | 标记距离均值超过若干个标准差的观测值。 | 适合近似平稳、轻尾分布的数据；当基线变化时，应使用滚动统计量或季节性统计量。 |
| Modified Z-score / MAD | 使用中位数绝对偏差，将观测值与中位数进行比较。 | 当历史数据中已经存在离群值时，它比均值和标准差更稳健。 |
| IQR 或分位数规则 | 标记落在稳健分位数边界之外的观测值。 | 简单且不依赖具体分布，但本身不会建模时间顺序。 |
| EWMA / CUSUM / 控制图 | 累积相对于受控基线的微小偏差。 | 适合检测受监控过程中的持续性水平偏移。 |
| 季节分解 | 移除趋势和季节性，再对残差评分。 | 适合需要在相同季节上下文中比较观测值的场景。 |
| 预测区间 | 拟合统计预测模型，并标记超出预测区间的观测值。 | 例如指数平滑和 ARIMA 系列模型。 |

对于观测值 \(x_t\)，普通 Z-score 使用均值和标准差：

\[
z_t = \frac{x_t - \mu}{\sigma}
\]

一种常见的稳健替代方案使用中位数和 MAD：

\[
\operatorname{MAD} = \operatorname{median}(|x_t - \operatorname{median}(x)|)
\]

`abs(z) > 3` 之类的阈值只是经验规则，并非通用常数。应在具有代表性的验证数据上估计阈值，并明确方差或 MAD 为零时的处理方式。

### 2. 传统机器学习

传统模型通常接收特征向量，而不是原始的带时间戳序列。特征可以包括当前值、滞后值、滚动统计量、差分、季节性残差、频域特征或完整的滑动窗口。

常见的 [scikit-learn 离群值与新颖性检测器](https://scikit-learn.org/stable/modules/outlier_detection.html)包括：

| 方法 | 典型用途 |
| --- | --- |
| Isolation Forest | 对表格特征或窗口特征进行无监督评分；扩展性较好，对数据分布的假设较少。 |
| Local Outlier Factor（LOF） | 查找相对于邻居具有异常低密度的样本。对未来数据进行评分时应使用 novelty 模式。 |
| One-Class SVM | 学习一个包围大部分正常训练样本的边界；对特征缩放和超参数比较敏感。 |
| Elliptic Envelope | 拟合稳健的高斯协方差；只适合高斯椭球形状假设合理的情况。 |
| 聚类或最近邻距离 | 将小型聚类或远离正常聚类的样本视为可疑对象。 |
| PCA 重构误差 | 标记无法由低维正常子空间良好表示的窗口。 |
| 监督分类器 | 当存在足够可靠的标签时，直接预测异常。 |

scikit-learn 是通用机器学习工具箱，本身并不是时序异常检测器。特征构建和训练/测试集划分必须保持时间顺序：缩放器、窗口生成过程和模型都只能使用过去的数据进行拟合，以避免数据泄漏。

### 3. 时序模型与深度学习模型

基于模型的检测器会直接学习时间结构或多变量结构。通常可以根据产生异常分数的机制进一步分类：

| 机制 | 基本思路 | 代表性模型 |
| --- | --- | --- |
| 基于预测（Forecasting-based） | 预测下一个值或窗口，并对预测残差或似然进行评分。 | 状态空间模型、RNN/LSTM/TCN、Transformer 预测模型。 |
| 基于重构（Reconstruction-based） | 重构正常输入窗口，并对重构误差进行评分。 | PCA、自编码器、变分自编码器、序列自编码器。 |
| 密度或概率方法 | 估计观测值或序列在所学习的正常过程下出现的可能性。 | 高斯过程、隐马尔可夫/状态空间模型、归一化流。 |
| 表示学习或图方法 | 在异常状态评分之前，学习时间关系和变量之间的关系。 | 对比学习模型、时序 Transformer、图神经网络。 |

[PyPOTS](https://github.com/WenjieDu/PyPOTS) 应归入这一部分，但它是一个**工具箱**，而不是某一种异常检测算法。它为部分观测数据上的多种神经时序模型和任务提供统一接口，其中包括异常检测和缺失值处理。具体的 PyPOTS 模型仍应被描述为基于预测、基于重构或基于表示学习的模型，而不能简单归类为“基于 PyPOTS”。

当时间依赖关系、多个相关变量、缺失观测或大规模数据使简单假设过于受限时，深度模型更有价值。不过，它们也需要更加谨慎的调参、校准和监控。

### 4. 基础模型与 LLM 辅助方法

这是一个仍在发展的类别，应区分为两个不同方向：

- **时序基础模型（Time-series foundation models）**会在大规模数值时序集合上进行预训练。它们可以提供预测、预测区间或嵌入表示；异常分数则可以来自预测误差或嵌入空间中的距离。
- **通用大语言模型（LLM）**通常更适合结合告警、日志、维护记录、指标名称和检测器输出等上下文信息使用。它们可以帮助解释、关联或分诊异常，但并不是天然经过校准的数值异常检测器。

基础模型可能有助于迁移学习和冷启动问题，但不能取代领域相关阈值、基于时间的评估、延迟检查和误报控制。对于许多生产指标，季节性基线、MAD 或 Isolation Forest 仍然更容易验证和运维。

## 学习设置

同一个算法类别可以应用于不同的监督假设：

- **基于规则（Rule-based）：**领域专家定义有效范围、变化率限制或逻辑约束。
- **无监督（Unsupervised）：**训练数据没有标签，并且可能包含少量异常。
- **半监督 / 新颖性检测（Semi-supervised / novelty detection）：**主要使用已知正常的历史数据进行训练，再检测对正常状态的偏离。
- **监督学习（Supervised）：**使用带有正常和异常标签的样本进行训练。
- **自监督学习（Self-supervised）：**通过预测、掩码或重构目标学习表示，再拟合异常分数或分类器。

## 如何选择起点

| 场景 | 建议的起点 |
| --- | --- |
| 一个稳定的单变量指标 | 滚动 Z-score、MAD、IQR 或控制图。 |
| 存在明显趋势或季节性 | 季节分解加残差评分，或使用预测区间。 |
| 有多个工程化特征但标签很少 | Isolation Forest、LOF 或 One-Class SVM。 |
| 有可靠的异常标签 | 使用基于时间验证的监督分类器。 |
| 有多个相关传感器或复杂序列异常 | 基于重构、预测或图结构的时序模型。 |
| 缺失的多变量观测是核心问题 | 面向部分观测时序设计的模型或工具箱，例如 PyPOTS。 |
| 数值告警伴随丰富的日志和运维上下文 | 先使用数值检测器，再用 LLM 辅助解释或分诊。 |

从能够捕获预期趋势和季节性的最简单方法开始。复杂模型应当在事件级指标上表现出相比统计基线和传统机器学习基线有意义的改进，而不只是拥有更低的训练损失。

## 实践流程

1. 定义异常单元：单个点、窗口、事件或状态变化。
2. 检查时间戳、重复值、缺失值、采样频率、趋势和季节性。
3. 按时间顺序划分训练、验证和测试时段；绝不能将未来观测随机混入训练特征。
4. 建立统计基线，例如使用季节性残差加 MAD。
5. 分别产生异常分数和决策阈值，不要将两者混为一体。
6. 根据业务成本或告警预算目标，在验证数据上选择并校准阈值。
7. 在更晚的留出时段上进行评估，并与基线比较。
8. 在生产环境中监控数据漂移、告警数量、缺失数据行为和阈值稳定性。

当异常持续跨越多个时间戳时，应优先使用事件级精确率、召回率和检测延迟。由于正常点通常占绝大多数，逐点准确率可能产生误导；如果把同一次事件中的每个异常点都视为独立的成功检测，也会夸大实际效果。
